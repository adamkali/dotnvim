

# Issue 09/08/2025 0 - Create a "task" workflow

## Summary
In this task what i want you to create is to make a workflow for the plugin that a user can specify a task 
in the `dotnetproject/.nvim` or `dotnetproject/.vscode` directory of the dotnet project and it will be loaded before debugging the project. 

the idea of this will to be able to have a json file: 
```json
/// .nvim/tasks.json // where the sln is 
{
    "version": "0.1.0",
    "tasks": [
        {
            "previous": "test",
            "name": "build",
            "command": "dotnet build",
            "cwd": ".",
            "env": {
                "DOTNET_NOLOGO": "true",
                "ASPNETCORE_ENVIRONMENT": "Development",
                "DOTNET_RUNNING_IN_CONTAINER": "true"
            }
        },
        {
            "name": "test",
            "command": "dotnet test",
            "cwd": ".",
            "env": {
                "DOTNET_NOLOGO": "true",
                "ASPNETCORE_ENVIRONMENT": "Development",
                "DOTNET_RUNNING_IN_CONTAINER": "true",
                "BYPASS_SECURITY": "c2f2b720-d55c-4f7e-a0fb-d95b2be80900"
            }
        }

    ]
}
```

and be able to have these commands be run before debugging the project. Ideally, we could extend the functionallity 
from dap to be able to run a task before debugging, for example the way to call dapui is:
```lua 
local dap = require "dap"
local dapui = require "dapui"

dap.listeners.before.launch.dapui_config = function()
    dapui.open()
end
```
